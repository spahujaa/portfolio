## Deploying

All images are embedded as base64 data URIs — no `/images` folder needed. Drop all files into the root of any static host and it works.

**GitHub Pages:** Push to a repo, enable Pages from Settings → Pages → Deploy from branch `main` / root.

**Custom domain:** Add a `CNAME` file to the repo root containing your domain (e.g. `sehejpahujaa.com`), then point your DNS A records to GitHub's IPs.
